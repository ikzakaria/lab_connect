# LabConnect

Application web React pour la gestion des analyses sanguines entre cabinets médicaux, agents de livraison et laboratoires.

## Installation

```bash
npm install
npm run dev
```

## Comptes de démonstration

| Rôle | Email | Mot de passe |
|------|-------|--------------|
| Médecin | doctor@labconnect.fr | doctor |
| Infirmier | nurse@labconnect.fr | nurse |
| Agent | agent@labconnect.fr | agent |
| Laboratoire | lab@labconnect.fr | lab |

## Fonctionnalités
- Création de demandes avec âge, sexe, photo, QR code
- Suivi du cycle de vie (6 statuts)
- Impression d'étiquettes
- Scan QR via caméra
- Génération de rapports PDF
- Synchronisation temps réel entre onglets
- Photo de profil patient cliquable sur toutes les vues
- Renommer / supprimer / éditer photo sur toutes les vues
